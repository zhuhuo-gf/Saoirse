02 · 获取通行凭证

连接你的 DeepSeek API。

API Key 由 DeepSeek 提供。Saoirse 不会上传或收集你的密钥，它只保存在本机的 Harness 配置中。

  1. 登录 DeepSeek 开放平台
  2. 在「API Keys」页面创建并复制密钥
  3. 余额不足时再前往充值页面
03 · 准备下潜

最后，在设置里保存密钥。

进入主界面后打开「设置」，找到模型或 API Key 配置，粘贴后保存。之后 Saoirse 会一直记住这台设备的配置。

  1. 进入 Saoirse 主界面
  2. 打开侧边栏或右上角的「设置」
